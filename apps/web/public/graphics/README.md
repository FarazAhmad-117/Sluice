# Illustration slots

Three commissioned illustrations, one per slot. Drop the finished file in this
folder under the filename below, then the slot's call site takes a `src` and the
dashed placeholder box goes away.

| File | Slot | Size | Page |
| --- | --- | --- | --- |
| `kill-switch.png` | The kill switch | 560 x 560 | homepage hero |
| `two-keys.png` | Two keys meet in the middle | 1200 x 640 | `/how-it-works` |
| `what-the-server-sees.png` | What the server can see | 1100 x 620 | `/security` |

Export at 2x (so 1120 x 1120, 2400 x 1280, 2200 x 1240) with a transparent
background. PNG or SVG. The site is dark locked, so nothing here needs a light
variant, and nothing here should carry its own background panel: it sits
directly on `--surface-base`.

The full brief for each one is the comment block directly above its call site,
which is the specification the artwork is checked against. Consolidated copy in
`docs/graphics-brief.md`.
